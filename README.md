# VS Code Tools

Shows remaining Codex usage limits (for example, **5h 75% · 7d 60%**) on the right side of the VS Code status bar. Hover to see reset times. Requires the Codex CLI to be installed and signed in with a ChatGPT account. Refreshes every two minutes.

Run `./install.sh` to package the current source and install it into VS Code. Run it again after changes to update the installed extension.

# VS Code Tools

Shows remaining Codex usage limits (for example, **5h 75% · 7d 60%**) on the right side of the VS Code status bar. Hover to see reset times and time left in days, hours, and minutes. Requires the Codex CLI to be installed and signed in with a ChatGPT account. Refreshes limits every two minutes and the countdown every minute.

Run `./install.sh` to package the current source and install it into VS Code. Run it again after changes to update the installed extension.
